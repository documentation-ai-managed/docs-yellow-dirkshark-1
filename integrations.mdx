## Linking with LEGO Official APIs

Connect Yellow DirkShark to LEGO's official APIs to fetch part data and instructions. Start by obtaining an API key from LEGO's developer portal.

<Callout kind="info">
  Replace `YOUR_API_KEY` with your actual LEGO API key.
</Callout>

Use this endpoint to search for parts:

<CodeGroup tabs="JavaScript,Python">
  ```javascript
  const response = await fetch('https://api.example.com/lego/parts?query=brick&api_key=YOUR_API_KEY');
  const parts = await response.json();
  console.log(parts);
  ```
  ```python
  import requests
  response = requests.get('https://api.example.com/lego/parts', params={
    'query': 'brick',
    'api_key': 'YOUR_API_KEY'
  })
  parts = response.json()
  print(parts)
  ```
</CodeGroup>

<ParamField path="query" param-type="string" required="true">
  Search term for LEGO parts, e.g., `brick 2x4`.
</ParamField>

<ParamField query="api_key" param-type="string" required="true">
  Your LEGO developer API key.
</ParamField>

## Setting up Webhooks for Project Updates

Webhooks notify your server when projects update, such as new builds or inventory changes. Follow these steps to configure one.

<Steps>
  <Step title="Create Webhook" icon="plus">
    In your Yellow DirkShark dashboard, navigate to Settings > Webhooks and click "New Webhook".
  </Step>
  <Step title="Set Endpoint" icon="link">
    Enter your endpoint URL, e.g., `https://your-webhook-url.com/webhook`.
  </Step>
  <Step title="Select Events" icon="settings">
    Choose events like `project.updated` or `inventory.changed`.
  </Step>
  <Step title="Test and Save" icon="check-circle">
    Send a test payload and save.
  </Step>
</Steps>

Expect payloads like this:

```json
{
  "event": "project.updated",
  "project_id": "proj_123",
  "timestamp": "2024-01-15T10:30:00Z"
}
```

## Integrating with Inventory Management Apps

Sync your Yellow DirkShark collection with popular inventory apps using OAuth or API tokens.

<Tabs>
  <Tab title="BrickLink" icon="package">
    Authorize via OAuth and map your sets.

    ```javascript
    const token = await exchangeCodeForToken('auth_code');
    const sync = await fetch('https://api.example.com/inventory/sync', {
      method: 'POST',
      headers: { Authorization: `Bearer ${token}` },
      body: JSON.stringify({ source: 'bricklink' })
    });
    ```
  </Tab>
  <Tab title="Rebrickable" icon="database">
    Use API v3 endpoints for bulk imports.

    ```javascript
    await fetch('https://api.example.com/inventory/import', {
      method: 'POST',
      body: JSON.stringify({ sets: ['123-1', '456-2'] })
    });
    ```
  </Tab>
</Tabs>

## Exporting Designs to 3D Printing Services

Export your LEGO designs as STL files for 3D printing. Yellow DirkShark generates print-ready models from your virtual builds.

```javascript
const exportData = await fetch('https://api.example.com/projects/export?project_id=proj_123&format=stl');
const blob = await exportData.blob();
const url = URL.createObjectURL(blob);
window.open(url); // Download or send to printer
```

<Callout kind="tip">
  Verify scale before printing—LEGO bricks are 8mm studs. Test with a single piece first.
</Callout>

<Expandable title="Advanced 3D Export Options">
  Customize tolerances and supports via query params:

  <ParamField query="tolerance" param-type="number" required="false">
    Clearance in mm, default `0.2`.
  </ParamField>
</Expandable>
