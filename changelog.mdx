## Recent Updates

<Update label="2024-10-15" description="v1.2.0" tags={["feature", "bugfix"]}>

## New Features

- Enhanced model builder with drag-and-drop piece placement from your LEGO collection.
- Share projects publicly or privately with customizable permissions.
- Integrated 3D preview for custom models before building.

## Improvements

- Faster loading of user-generated instructions using optimized caching.

## Bug Fixes

- Fixed sharing functionality that prevented exports for models over `>500` pieces.
- Resolved authentication errors during collaborative editing sessions.

</Update>

<Update label="2024-09-20" description="v1.1.0" tags={["feature", "improvement"]}>

## New Features

- Advanced search filters for LEGO pieces by color, category, and year.
- Bulk import from Rebrickable MOCs directly into your collection.

## Improvements

- Model building interface now supports undo/redo up to 50 actions.
- Key enhancements in rendering performance for large inventories.

</Update>

<Update label="2024-08-10" description="v1.0.0" tags={["feature", "breaking"]}>

## New Features

- Core platform launch with collection inventory management.
- Browse and build from thousands of user-submitted LEGO designs.
- Downloadable PDF instructions for verified projects.

## Breaking Changes

- Updated API endpoints from `/v0/` to `/v1/` paths. Migrate using the guide below.

```javascript
// Old endpoint (deprecated)
fetch('https://api.example.com/v0/models');

// New endpoint
fetch('https://api.example.com/v1/models');
```

</Update>

## Upgrading to the Latest Version

<Steps>
  <Step title="Check Current Version" icon="check-circle">

    Visit your dashboard at `https://dashboard.example.com/account` to view installed version.

  </Step>
  <Step title="Review Changes" icon="book-open">

    Scan the updates above for breaking changes, especially API paths.

  </Step>
  <Step title="Update Client SDK" icon="download">

    <CodeGroup tabs="npm,yarn">
    ````bash
    npm install yellow-dirshark-sdk@latest
    ````
    ````bash
    yarn add yellow-dirshark-sdk@latest
    ````
    </CodeGroup>

  </Step>
  <Step title="Test Models" icon="play-circle">

    Rebuild a sample project to verify piece compatibility.

  </Step>
</Steps>
